## Deterministic task generation

**Six families,20 slots each**, in this order: `integer`, `modular`, `division`, `dp`, `graph`, `aggregation`. Slots are integers0..19. Master seed is **20261105**. For each family/slot/attempt, use a separate Python standard-library MT19937 stream:

```python
label = f"compute-dl-v1|20261105|{family}|{slot}|{attempt}"
seed = int.from_bytes(hashlib.sha256(label.encode("ascii")).digest(), "big")
r = random.Random(seed)
```

Pin Python version and the generator source before generation. `randint(lo,hi)` is inclusive, `randrange(lo,hi)` excludes hi. Every list traversal specified below is ascending/lexicographic before any explicit shuffle. `digits(d)` means one `r.randrange(10**(d-1),10**d)` draw. Start attempt0; increment only for a documented disjointness collision, never for a verification failure/difficulty/length/call-rate judgement. Each slot's stream is independent of other slots' rejection counts; stop with a preparation failure after1000 collisions. IDs are `compute-dl-v1-{family}-{slot+1:03d}`. Store generator label/attempt, typed inputs, canonical prompt and both references.

Draw inputs **in exactly this sequence**:

| Family | Generation and requested quantity | Independent reference A / B |
|---|---|---|
| integer | `a=digits(r.randint(24,36)); b=digits(r.randint(24,36)); c=r.randrange(-10**20,10**20+1)`. Answer `a*b+c`. | Python arbitrary integers / Decimal integer arithmetic at precision256 with Inexact/Rounded traps, never floats |
| modular | `a=digits(r.randint(14,20)); e=r.randint(500,5000); m=digits(r.randint(16,22))`. Least nonnegative residue of `a**e` modulo m; no primality assumption. | `pow(a,e,m)` / start1, multiply by a and reduce modulo m **e times**, independently implemented |
| division | `a=digits(80); b=digits(29)`, both positive. Unique q,r satisfying `a=q*b+r`, `0<=r<b`. | Python `divmod` / Decimal integer quotient/remainder at precision256, plus independent identity/range checks |
| dp | `rows=r.randint(7,10); cols=r.randint(7,10)`; row-major matrix entries `r.randint(0,99)`. Minimum visited-cell sum from top-left to bottom-right, right/down only, endpoints included. | Rolling-row minimum-cost DP / recursively enumerate **all** monotone paths and minimize exact sums; maximum48620 paths |
| graph | `n=r.randint(9,14)`; add backbone `(i,i+1,r.randint(1,40))` for i0..n-2. Build lexicographic pairs `(u,v)` with u!=v excluding backbone; shuffle once; draw `k=r.randint(n,2*n)`; take first k pairs and draw weight1..40 for each in that order. Sort final edge triples by(u,v). Directed shortest distance0→n-1. | Heap Dijkstra / independently implemented Floyd–Warshall. Backbone guarantees reachability; no self/duplicate edges |
| aggregation | `count=r.randint(40,60)`; labels `A..F`. For each i0..count-1 use label i for first6, otherwise `labels[r.randrange(6)]`, then quantity `r.randint(1,20)`, amount `r.randint(-999,1999)`. Shuffle records once. Answer map of each label to sum(quantity*amount), integer cents. | Single-pass dict accumulation / sort records by label then separately fold each group |

Serialize embedded matrices/edges/records with `json.dumps(value,ensure_ascii=True,separators=(",",":"))`; maps use sorted keys. Use the following **fixed user prompt templates**, substituting only the generated values. Do not mention tools, code, the arm, time pressure or answer-checking hints:

- Integer: `Compute A*B+C exactly for A={a}, B={b}, C={c}. Final answer format: a JSON integer.`
- Modular: `Find the least nonnegative residue of A^E modulo M, where A={a}, E={e}, M={m}. Here ^ denotes exponentiation. Final answer format: a JSON integer.`
- Division: `For A={a} and B={b}, find integers q and r such that A=q*B+r and 0<=r<B. Final answer format: the JSON array [q,r].`
- DP: `A path starts at the top-left cell of this grid and ends at the bottom-right cell. Each move is one cell right or one cell down. The path cost is the sum of all visited cells, including both endpoints. What is the minimum cost? Grid: {matrix}. Final answer format: a JSON integer.`
- Graph: `A directed graph has vertices 0 through {n_minus_1}. Each edge [u,v,w] goes from u to v with cost w. What is the minimum total cost from vertex 0 to vertex {n_minus_1}? Edges: {edges}. Final answer format: a JSON integer.`
- Aggregation: `Each transaction is [category,quantity,unit_amount]. Unit amounts are signed integer cents. For each category A through F, compute the sum of quantity*unit_amount over its transactions. Transactions: {records}. Final answer format: a JSON object with keys A through F and integer values.`

Independently implement A/B; B must not call A, import its answer file or copy its intermediate tables. Run separately from the same typed input manifest, then compare exact typed outputs for all120 tasks. Keep successful and failed checks. Reference disagreement, malformed input, graph invariant failure or Decimal rounding **stops preparation**, not regeneration. Check known small examples and deliberately wrong answer/mutated-input controls before sealing. No generated code/model answer is executed on the dev box. These bounded reference computations fit the node CPU scope; no engine build is required.
