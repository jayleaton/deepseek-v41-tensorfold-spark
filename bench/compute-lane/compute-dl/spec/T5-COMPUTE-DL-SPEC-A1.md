Retention eligibility is not a declaration that those remaining implementation checks have already passed.

Reference pipeline, in production order:

1. Bind each call's exact source/state, native status and inserted result frame to the original native IDs. Re-run/check independent CPython in the existing isolated jail; preserve stdout, stderr, exit/status, output-byte/time limits and replay provenance. Construct the complete reference body using the pinned native status/body/normalization policy, not merely stdout for every status. Native/reference status differences cannot be disguised by equal prefixes.
2. Match the actual pinned `compute_segments.capTokens`, effective limit **512**, tokenizer bytes and plain-text codec. Let `ids=encodePlain(full_reference_body)`. If its length≤512, expected output is the complete body unchanged, **without adding a marker**. If longer, start n=512 and reduce n until decoding `ids[:n]` yields valid UTF-8. Expected bytes are that prefix followed by exactly `\n[output truncated at 512 tokens]`; if no nonempty valid prefix exists, use exactly `[output truncated at 512 tokens]`. Reproduce all preceding native byte/status limits as well. Do not count the marker inside the512 prefix budget; aggregate8192 returned-ID accounting still includes all actual inserted protocol/result IDs.
3. Compare exact expected/native delivered bytes, status and frame/source bindings. Keep clipped and unclipped qualifications separate. No character-count estimate, alternate tokenizer, special-token/prompt-render substitution, whitespace repair or marker-stripping shortcut. Any encoder failure or unsupported reference-policy branch is unqualified and stops collection, not an automatic clipping exemption.

Before resumption seal controls for511/512/513-token bodies, empty output, long output,2/3/4-byte UTF-8 seams, stdout/stderr/error/status handling, exact marker spelling/placement, a marker naturally printed **below** the cap, altered landed prefix bytes, false native markers on short outputs, source/status swaps and missing frames. Mutations affecting delivered bytes must fail; an independent-reference change entirely beyond the retained prefix can be observationally indistinguishable after clipping, and must not be advertised as detected. Compare the codec/policy against the real pinned native implementation on CPU; a wrapper that merely returns the observed prefix is insufficient.

Report `presentation-verified clipped` counts, full-reference and landed-body lengths/hashes, retained prefix length and marker bytes. This authenticates the **landed presentation**, not every invisible tail byte or a complete uncropped printed value. Never count a clipped fragment as a verified complete answer.
